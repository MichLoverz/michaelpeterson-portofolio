# Michael Peterson — Portfolio

Personal portfolio website built with **Next.js 16**, **React 19**, and **Tailwind CSS v4**.

## Run locally

```bash
npm install       # first time only
npm run dev       # start dev server at http://localhost:3000
```

## Where to edit content

- [`app/lib/data.ts`](app/lib/data.ts) — name, tagline, about text, contact
  links, development projects, and skills.
- [`app/lib/design.ts`](app/lib/design.ts) — design collection titles/intros
  and the YouTube IDs for videos.

Fields marked `// TODO(michael)` are drafts — review and replace them.

## Design gallery (images)

Raw design files live in `Portofolio (by Folder)/` (git-ignored, too large).
The site uses optimised WebP copies generated from them:

```bash
npm run gallery
```

This reads `Portofolio (by Folder)/<Brand>/<Folder>/...`, writes WebP thumbs
and full-size copies to `public/design/`, and regenerates
`app/lib/gallery.json`. Re-run it whenever you add or change files. Which
folders map to which collection is set in `scripts/build-gallery.mjs`.

### Adding a project screenshot

1. Put the image in `public/projects/` (e.g. `public/projects/wine.png`).
2. In `app/lib/data.ts`, set the project's `image` field, e.g.
   `image: "/projects/wine.png"`.

### Adding your resume

1. Put `resume.pdf` in the `public/` folder.
2. In `app/lib/data.ts`, set `resumeUrl: "/resume.pdf"`. A download button
   appears automatically.

## Structure

```
app/
  layout.tsx          # metadata / SEO, fonts
  page.tsx            # home: Hero, Profile, Development, Design, Skills, Contact
  design/page.tsx     # /design — all collections
  design/[slug]/      # /design/<collection> — gallery with lightbox
  globals.css         # theme tokens (colors, fonts)
  lib/data.ts         # ← profile, development projects, skills
  lib/design.ts       # ← design collections + videos
  lib/gallery.json    # generated by `npm run gallery` (don't edit by hand)
  components/
scripts/build-gallery.mjs   # image pipeline
public/projects/            # ← development project screenshots
public/design/              # generated WebP gallery images
Portofolio (by Folder)/     # raw design files (git-ignored)
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Go to [vercel.com](https://vercel.com), sign in with GitHub, and click
   **Add New → Project**.
3. Import the repo. Vercel auto-detects Next.js — no config needed. Click
   **Deploy**.
4. You'll get a free `*.vercel.app` URL. Add a custom domain later in
   Project → Settings → Domains.
